# Viren als Vektoren
der einstatz von [[Viren]] als Vektor zur insertion genetischen materials in Zellen ist der Primäre vorgang der Gentherapie.
so können z.B. fehlerhafte genabschnitte ausgeschnitten, ersetzt werden, oder fehlende hinzugefügt werden.

Dies kann in-vivo, im körper, oder ex-vivo, auserhalb des körpers, z.B. an Stammzellen auserhalb des Körpers, geschehen.

Viren befallen allerdings nur bestimmte zellen. Das [[CRISPR-Cas]]9 System kann hier hildfreich sein.
