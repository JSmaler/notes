Selektion ist, an sich, bloß die Auslese der schlecht auf die umwelt einer [[Population]] angepasste Allele.
Wenn diese Selektion von Menschen ausgeht, wird sie als Züchtung bezeichnet.

Natürliche Selektion kann von vielerlei faktoren ausgehen. Abiotische; Wind, Temperatur, Feuchtigkeit, Licht, genauso wie Biotische; Fressfeinde, Parasiten (**Zwischenartige Selektion**), aber auch von Artgenossen (Innerartliche Selektion, was z.B. zu Sexualdimorphismus führt).

Selektion kann auf eine Population Stabilisierend, Gerichteten oder Aufstpaltenden sprechen.

**Stabilisierende Selektion** "Stabilisiert" eine Population an einem Punkt. Individuen die vom Durchschnitt abweichen haben einen nachteil, der status quo wird verstärkt.

**Gerichtete Selektion** verschiebt eine gesamte Population in eine spezifische richtung. Individuen die in einer spezifischen weise vom Durchschnit abweichen haben einen vorteil. So werden z.B. Kleinere Fische weniger gefressen. Somit werden Kleinere Fische langfristig einen Überlebensvorteil haben, und alle individuen in der population werden langfristig kleiner sein.

**Aufspaltende Selektion** "teilt" eine Population. Individuen die vom durchschnit abweichen, egal in welche richtung, haben einen vorteil gegenüber denen im durchschnit. Hiermit wird die Population langfristig in zwei, in beide richtungen verschobene Populationen gespalten. So haben z.B. Größere Fische es leicher fressen zu finden, und kleinere Leichter nicht gefressen zu werden. Somit bildet sich eine Population immer größerer Fische, und eine immer Kleinerer, die sich langfristig nichtmehr miteinander fortpflanzen können, und so in zwei populationen gespalten werden.
