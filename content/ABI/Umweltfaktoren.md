Umweltfaktoren sind die von außen, aus der Umwelt, auf einen [[Organismus]], oder ein [[Biotop]] einwirkenden Faktoren. Diese können **Biotisch** -*belebt*, oder **abiotisch** - *unbelebt* sein.

# Biotische Umweltfaktoren
Biotische Umweltfaktoren sind solche die von anderen Lebewesen ausgehen, wie z.B. Nahrung, Konkurrenz, Krankheitserreger, Fressfeinde etc.

# Abiotische Umweltfaktoren
Abiotische Umweltfaktoren sind solche, die von unbelebten Elementen ausgehen, wie z.B. Temperatur, Wasser, Licht, pH-Wert etc.

# Toleranzkurven

Wenn ein sich verändernder Umweltfaktor auf die Lebensaktivität eines Organismus gemessen wird, ergibt sich eine charakteristische **Toleranzkurve**.

Erträgt eine Art keine großen Schwankungen eines Umweltfaktors, ist diese **stenök**. Erträgt sie hingegen große Schwankungen, ist sie **euryök**.

Mit ausnahmen, wie z.B. Krankheitserregern, hat die Toleranzkurve eine Glockenform. In der Mitte, rund um das Optimum gibt es einen Vorzugsbereich, welchen die Art, in Abwesenheit anderer Einflüsse, suchen wird. Hierum gibt es noch einen weiteren Bereich ökologischer Potenz, in welchem eine [[Art]] überdauern, und sich vermehren kann. Hier kann eine Population überleben.
Am Rande des Toleranzbereichs, der ganzen breite der Kurve, findet sich das pessimum. Dies kann die Pflanze zwar überleben, doch kann sie sich hier nicht vermehren, und eine Population wird aussterben. Ein Beispiel wäre Rasen, welcher während einer Flut unter Wasser steht. Er kann überleben, doch sollte er permanent unter Wasser stehen, würde die Population absterben.

Im Labor bestimmte Toleranzkurven werden nicht immer in der Natur 1:1 abgebildet. Dies liegt daran, dass unterschiedliche Umweltfaktoren sich gegenseitig beeinflussen. So kann z.B. der von der Lichteinstrahlung für eine Pflanze perfekte Bereich zu feucht sein, oder bereits von anderen Konkurrenten besetzt sein.

Eine [[Ökologische Nische]] ist die Gesamtheit der Ansprüche einer Art an ihre Umwelt.
