# Gendrift
Zufällige veränderungen [[Mutation|Mutationen]] verändern den Genpool, und somit die Allelfrequenz andauernd, wobei natürlich kleinere Populationen deutlich schwerer betroffen sind als größere.

Das spielt bei Inselpopulationen (gründereffekt) eine wichtige rolle, doch auch bei anderen Populationen kann, z.B. durch Hungersnöte ein Flaschenhalz-Effekt auftreten, welcher die Population verringert.

# Migration
Der genpool einer Population kann dadurch verändert werden das individuen Zu/Ab wandern.

# isolation
Eine Population die von einer anderen Isoliert ist, wird natürlichauseinanderdriften. Für Isolierte Populationen gelten meist auch andere Selektionsfaktoren aufgrund ihrer meist unterschiedlichen [[Ökologische Nische|Ökologische Nischen]].
Es gibt mehrere Arten der [[Isolation]].
